3. 測試目的 / Test Purpose

透過自動辨識照片中的雷射打點與座標紙標定點位置，量化雷射裝置的準確度（Accuracy）與重複性（Repeatability），取代人工讀數以降低主觀誤差。

Automatically detect laser spot positions and coordinate paper reference markers in photos to quantify the laser device's accuracy and repeatability, replacing manual reading to reduce subjective error.

5. 前置作業 / General Requirement before testing

  1. 確認座標紙平整無皺褶、無污損 / Ensure coordinate paper is flat, unwrinkled, and clean
  2. 確認雷射裝置穩定固定（拍攝過程中不可晃動）/ Ensure laser device is stably mounted
  3. 環境光不要過亮，避免反光蓋過雷射核心；也不可過暗造成標定點 hue 偏移 / Avoid overly bright or dim lighting
  4. 拍攝時整張座標紙（含 8 個彩色標定點）完整在畫面內 / Whole coordinate paper fully visible in frame
  5. 相機對焦清晰、沒有明顯動態模糊 / Camera focused; no motion blur
  6. 同一批測試的所有照片建議保持相同視角／距離 / Keep camera angle and distance consistent
  7. 建議首次或更換鏡頭後拍一張校正參考圖 / Take one calibration reference image on first use or after lens change

6. 測試步驟 / Test Procedure

Step 1 — 上傳照片 / Upload images

  1. 用瀏覽器開啟工具網頁 / Open the tool in browser
  2. Page 1（上傳圖片）將照片拖曳到虛線框，或按「選擇圖片」/ Drag photos or click "Select Images"
  3. 單次最多 30 張 / Up to 30 images per session
  4. 右下角浮動橫幅會顯示下一步建議 / Bottom-right banner shows next-step suggestion

Step 2 — 鏡頭校正（強建議）/ Lens calibration (strongly recommended)

  1. 按 Page 1 頂部「📷 上傳校正參考圖」/ Click "📷 Upload Calibration Reference"
  2. 選擇校正參考圖 → modal 自動開啟 / Select reference image → modal opens
  3. 標定原點 (0,0)、R1 (3,0)、R2 (6,0) 等已知點位 / Mark origin, R1, R2 reference points
  4. 按「📐 設為鏡頭校正基準」/ Click "📐 Set as Lens Calibration"
  5. 校正圖會自動隱藏，不算入 30 張工作集 / Cal-ref auto-hidden, not counted toward 30
  6. 校正資料會被「💾 .zip」存檔保留 / Calibration preserved by .zip save

Step 3 — 自動辨識 / Auto-detection

  1. 確認校正完成（橫幅變黃色 ⚡）/ Confirm calibration set (yellow ⚡)
  2. 按「▶ 自動辨識全部」/ Click "▶ Auto-detect All"
  3. 等候進度條完成 / Wait for progress bar
  4. 完成後自動跳到 Page 2 / Auto-jumps to Page 2 when done

Step 4 — 逐張審閱與微調 / Per-image review and fine-tune

  1. Page 2 縮圖直接顯示偵測結果：
    • 黃色十字 = 偵測到的原點 (0,0)
    • 藍色圈 = 雷射 P1（左）
    • 紅色圈 = 雷射 P2（右）
    Yellow cross = origin; Blue = Laser P1 (left); Red = Laser P2 (right)
  2. 掃過全部縮圖，確認對準位置 / Scan all thumbnails
  3. 需微調者點該縮圖開啟 modal / Click thumbnail to open modal
  4. modal 內可拖曳重設原點、雷射點、座標軸 / Drag to reset positions in modal
  5. 確認後按「儲存」標記為手動確認 / Click "Save" to mark as manually saved
  6. 已手動確認的張數重跑時會被略過 / Manually-saved images are skipped on next run

Step 5 — 前往輸出 / Go to output

  1. 按「下一步：輸出結果 →」/ Click "Next: Output →"
  2. 系統跳出確認視窗 / Confirmation dialog appears
  3. 確認後進入 Page 3 / Proceed to Page 3
